  DeepSeek dsh Desktop 使用说明
════════════════════════════════════════════════════════

★★★ 打不开？请先看这里 ★★★
如果双击应用时提示：
  · 「"dsh-desktop" 已损坏，无法打开。您应该将它移到废纸篓」
  · 或「无法验证开发者」且按下方方法仍打不开
这是 macOS 给从网络下载的应用加上了"隔离标记"导致的，
应用本身并没有损坏。打开「终端」（Terminal），粘贴执行：

    sudo xattr -cr /Applications/dsh-desktop.app

然后输入开机密码（输入时屏幕不会显示，属正常），回车后再双击
应用即可正常打开。
※ 若应用不在「应用程序」文件夹，请把上面路径换成实际位置。

────────────────────────────────────────────────────────
【这是什么】
dsh-desktop 是 DeepSeek dsh 命令的桌面版启动器。
打开后会自动完成以下事情：
  1. 检查电脑上有没有 Node.js 运行环境（要求 v22.15 以上）
  2. 没有或版本过低时，自动下载一份便携版 Node（约 30MB，
     存放在 ~/.cache/dsh-desktop，不需要管理员权限，也不污染系统）
  3. 启动 dsh 的网页服务，并自动打开内置界面
  4. 关闭窗口时，后台服务会一并停止，不留残留进程

────────────────────────────────────────────────────────
一、安装
────────────────────────────────────────────────────────
1. 将本窗口左侧的 "dsh-desktop.app" 拖到右侧 "Applications" 文件夹
2. 在「启动台」或「应用程序」文件夹中找到 dsh-desktop，双击打开

◆ 首次打开如果提示「无法打开，因为无法验证开发者」：
   这是 macOS 对未上架应用的通用提示，处理方式任选其一：
   · 打开「系统设置」→「隐私与安全性」→ 拉到底点击「仍要打开」
   · 或者：在「应用程序」里右键点 dsh-desktop → 选「打开」→ 再点「打开」

────────────────────────────────────────────────────────
二、首次启动（请耐心等待）
────────────────────────────────────────────────────────
首次打开时，窗口里会像终端一样滚动显示启动日志，这是正常的：
  · 环境自检：检查 Node.js 是否存在、版本是否达标
  · 自动下载：缺少 Node 时会显示下载进度（取决于网速，一般 1~3 分钟）
  · 依赖下载：dsh 命令首次运行需要联网获取依赖包，可能耗时几分钟，
    状态栏会持续提示「正在下载 / 初始化依赖」，请不要关闭窗口
  · 看到服务地址（http://127.0.0.1:3080）后，界面会自动跳转到 dsh 主界面

之后再打开就快多了：已下载过的 Node 和依赖包会直接复用。

────────────────────────────────────────────────────────
三、日常使用
────────────────────────────────────────────────────────
· 直接使用 dsh 的网页功能即可，体验与浏览器版一致
· 窗口标题栏右侧有三个控件：
    [检查更新]  检查并自动安装新版本（详见下节）
    [帮助]      打开帮助/关于窗口，含常见问题说明
    [v版本号]   当前应用版本
· 用完直接关闭窗口即可，后台服务会自动停止
· 剪贴板快捷键 ⌘C / ⌘V / ⌘A / ⌘Z 在输入框内均可正常使用

────────────────────────────────────────────────────────
四、自动更新
────────────────────────────────────────────────────────
点击标题栏「检查更新」：
  · 有新版本时会弹出确认框，展示更新说明，点确认后自动下载安装
    （安装包经过签名校验，安全可靠）
  · 安装完成后按提示重启应用即可生效
  · 没有网络时会自动跳过检查，不影响正常使用

────────────────────────────────────────────────────────
五、遇到问题怎么办
────────────────────────────────────────────────────────
◆ 提示「端口 3080 被占用」
  一般是上次没有正常退出导致的残留进程，应用会尝试自动清理。
  若仍提示占用，可打开「终端」执行：
      lsof -iTCP:3080 -sTCP:LISTEN
  找到对应 PID 后执行 kill -9 <PID>，再重新打开应用。

◆ 启动后一直卡住不动
  先看窗口内终端输出的具体报错信息。也可以把调试日志发给开发者：
      /tmp/dsh-desktop-debug.log

◆ 下载 Node 或依赖特别慢 / 失败
  检查网络连接后重开应用重试；也可以自行安装 Node.js（v22.15+），
  应用会优先使用系统里已有的 Node。
  已有 Node 但想强制用便携版？在「终端」执行：
      open -a dsh-desktop --env DSH_NPX=/path/to/npx
  或设置环境变量 DSH_NPX 指定你想要的 npx 路径。

◆ 想彻底重置运行环境
  删除缓存目录后重开应用即可（会重新下载 Node）：
      rm -rf ~/.cache/dsh-desktop

────────────────────────────────────────────────────────
六、卸载
────────────────────────────────────────────────────────
1. 在「应用程序」文件夹中删除 dsh-desktop.app
2. （可选）清理缓存目录：rm -rf ~/.cache/dsh-desktop
