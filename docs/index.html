dsh-desktop

把 DeepSeek dsh web 装进一个原生桌面窗口——双击即用，关窗即停。

Rust tao + wry 跨平台 自包含二进制
⬇ 下载发布版 ★ GitHub 源码

01 功能特性

不是简单的"套壳浏览器"，而是一个真正可交付给非技术用户的桌面应用。

⚡

开箱即用

双击 App，自动运行 npx -y @deepseek-ai/dsh web，无需手动敲命令、无需装 Node。

🖥️

内置交互终端

实时显示命令输出（彩色、进度条、光标移动），底部输入框可手动回复确认提示，行为与真实终端一致。

🤖

智能自动应答

检测到 (y/N) 确认时自动回复 y，黄色横幅原样展示问题文字，关闭回显避免噪音。

🔍

环境自检 + 便携 Node

启动前逐项检测环境；Node 版本过低或缺失时，自动从国内镜像下载便携版 v22.23.2，零额外配置。

🧹

干净退出

关闭窗口即 killpg 杀掉整个进程组（含 npx 拉起的 node 子进程），不留后台残留。

📦

自包含二进制

HTML / JS / 图标全部 include_str! 编译期内嵌，产物完全自包含，各平台只需分发二进制本身。

02 工作原理

从双击到看到界面，中间发生了什么？

环境自检 → 打印检测清单（✓/✗），找到 npx 则复用，否则自动下载便携版 Node.js
启动命令 → 以伪终端（PTY）运行 npx -y @deepseek-ai/dsh web，内置终端实时显示输出
端口就绪 → 轮询 127.0.0.1:3080，一旦就绪自动跳转，窗口显示 dsh 的 Web 界面
关闭窗口 → killpg 杀掉整个进程组，干净退出

03 怎么用

到 Releases 页下载对应平台包，双击即可。

🍎 macOS
.dmg（aarch64 / x86_64）
拖入「应用程序」；首次被拦截右键「打开」或 xattr -cr
🐧 Linux
.tar.gz
解压后运行；需系统已装 webkit2gtk-4.1
🪟 Windows
.zip
解压后运行 .exe；Win11 自带 WebView2
# 从源码构建运行
cargo run --release

# 打包 macOS .app
./package-macos.sh

# 打包可分发 .dmg
./package-dmg.sh

04 技术栈

和 Tauri 同源，但更底层、更轻量——因为要启动的是外部子进程，不是自己的前端。

Rust 系统语言 tao 0.30 窗口管理 wry 0.49 原生 WebView libc::forkpty 伪终端（PTY） include_str! 编译期内嵌资源 GitHub Actions 跨平台自动发版 
src/
├── main.rs        # 入口：窗口/webview、事件循环、进程句柄
├── environment.rs # 环境自检 + 便携 Node 下载
├── terminal.rs    # PTY/管道启动子进程 + 输出读取
└── ui.rs          # HTML/JS 资源 + 字符串转义工具
